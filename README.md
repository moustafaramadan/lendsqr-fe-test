# Lendsqr Frontend Assessment

React, TypeScript, and SCSS implementation of the Lendsqr frontend engineering assessment.

## Features

- Login page with local session storage
- Dashboard page with summary cards and recent users
- Users page backed by a 500-record mock API
- User details page that stores and retrieves fetched user records from `localStorage`
- Responsive layouts for desktop, tablet, and mobile breakpoints
- Component-level SCSS files colocated with their React components
- Unit tests covering positive and negative scenarios

## Tech Stack

- React 19
- TypeScript
- Vite
- SCSS / Sass
- Vitest
- Testing Library

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Run tests:

```bash
npm test
```

## Testing Coverage

The test suite includes:

- Positive mock API scenario: returns paginated users from the 500-record dataset
- Negative mock API scenarios: empty query results and missing user detail records
- Positive storage scenario: saves and retrieves a user detail record
- Negative storage scenario: handles invalid stored JSON safely
- Positive login scenario: valid form submission stores the session
- Negative login scenario: required empty fields do not submit

## Assessment Notes

The app follows the requested React + TypeScript + SCSS stack. User data is generated by a local mock API in `src/data/mockApi.ts`, and detail records are cached through `src/data/userStorage.ts`. The UI is split into focused components with each component owning its SCSS where practical.
